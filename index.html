About the course

Business Analytics (ITMA-501) covers the fundamental concepts of the emerging field of business data analytics. It promotes the applicable use of artificial intelligence models and software tools to develop the qualitative, quantitative, and managerial skills necessary to analyze complex data sets.

The course enables students to apply data-driven analytics to support strategic decision making in competitive and dynamic local and global markets, implementing Big Data knowledge across processes, products, services, and consumer profiles to improve organizational competitiveness and sustainability.

Methods

Descriptive, diagnostic, predictive, and prescriptive analytics, grounded in real datasets.

Tools

Statistical software (SPSS, R, PSPP), Power BI, SQL, and modern ML libraries (scikit-learn, TensorFlow, PyTorch).

Outcomes

Make defensible, data-driven recommendations that hold up in a competitive business context.

Syllabus

Eight units, 45 sub-topics. Unit titles and sub-topic names are preserved verbatim from the official UAGM syllabus in Spanish. Numbering has been normalized for clarity (see lecture notes for the original numbering, where it differed).

Unidad 1Introducción a la analítica de negocios
  • 1.1 Métodos y modelos analíticos (descriptivo, diagnóstico, predictivo y prescriptivo)
  • 1.2 Big Data (volumen, velocidad, variedad y veracidad)
  • 1.3 Datos estructurados, semi-estructurados y no estructurados
  • 1.4 Analítica de negocios en la práctica (cadena de suministro, financiero, marketing, recursos humanos y Web)
Unidad 2Visualización de datos
  • 2.1 Descripción general de la visualización de datos
  • 2.2 Técnicas de diseño efectivos para la generación de visualizaciones
  • 2.3 Principios de diseño de tablas, tabulación cruzada
  • 2.4 Tablas dinámicas (Power BI y Excel)
  • 2.5 Gráficos circulares, gráficos tridimensionales, gráficos de burbujas, mapas de calor
  • 2.6 Otros gráficos adicionales para múltiples variables
  • 2.7 Gráficos dinámicos
  • 2.8 Indicador clave de desempeño (KPI)
Unidad 3Análisis de bases de datos relacionales y otras fuentes de datos
  • 3.1 Importación de datos a través de un sistema de bases de datos relacional (SQL Server, Oracle Developer u otro)
  • 3.2 Aplicación sentencias SELECT, FROM y WHERE
  • 3.3 Funciones agregadas para la creación de consultas estructuradas
  • 3.4 Álgebra relacional para la creación de consultas estructuradas
  • 3.5 Exportación de datos a través de un sistema de bases de datos relacional
  • 3.6 Creación de reportes de información (Reporting Services, Excel u otro) para la toma de decisiones
  • 3.7 Transformación de bases de datos secundarias (Pew Research Center, World Values Survey, Kaggle, u otras)
  • 3.8 Elaboración de encuestas, QR Code y exportación de datos a través de Microsoft Forms
Unidad 4Minería de datos descriptivos
  • 4.1 Análisis de conglomerados
  • 4.2 Distancia entre observaciones
  • 4.3 Agrupamiento de k-medias y agrupamiento jerárquico
  • 4.4 Medición de la disimilitud entre conglomerados
  • 4.5 Reglas de asociación (evaluación de las reglas de asociación)
  • 4.6 Minería de texto
  • 4.7 Preprocesamiento de datos de texto para análisis
  • 4.8 Disimilitud entre documentos y nubes de palabras
Unidad 5Introducción a la inteligencia artificial
  • 5.1 Definición de la inteligencia artificial
  • 5.2 Tipos de inteligencia artificial
  • 5.3 Aplicaciones y casos de uso actuales
  • 5.4 Ética y consideraciones sociales
Unidad 6Aprendizaje Automático (Machine Learning)
  • 6.1 Aprendizaje supervisado
  • 6.2 Máquinas de soporte vectorial (SVM)
  • 6.3 Redes neuronales y aprendizaje profundo (Deep Learning)
  • 6.4 Métodos random forests y boosting
Unidad 7Aprendizaje no supervisado
  • 7.1 Clustering (k-means y jerárquico)
  • 7.2 Reducción de dimensionalidad (PCA, t-SNE)
  • 7.3 Aprendizaje por refuerzo
  • 7.4 Algoritmos básicos (Q-learning, SARSA)
  • 7.5 Políticas y valoraciones
Unidad 8Desarrollo y herramientas
  • 8.1 Entorno de aplicación de algoritmos de análisis (Rapid Miner)
  • 8.2 Entornos de desarrollo (Jupyter, Colab)
  • 8.3 Bibliotecas y frameworks (TensorFlow, PyTorch, scikit-learn)
  • 8.4 Implementación y optimización de modelos

Tools & lab

This course is lab-required. You will need software for two distinct phases of the term.

Statistical analysis (Units 1 to 4)

  • SPSS, PSPP, R, or MegaStat — at least one. Free options (PSPP, R) are sufficient for every assignment.
  • Power BI Desktop and Microsoft Excel for visualization and pivot work.
  • A SQL environment (SQL Server Express, SQLite, or DB Browser for SQLite) for Unit 3.

Machine learning (Units 5 to 8)

  • Python 3.11+ with scikit-learn, pandas, numpy, matplotlib.
  • Jupyter Notebook or Google Colab (Colab is recommended; no local setup required).
  • Optional: TensorFlow or PyTorch for deep-learning exercises.
  • RapidMiner Studio (free educational license) for Unit 8.
Install before L02

Bring your laptop to every session, with at least one statistical tool and Python (or a working Colab account) installed and verified. We will reconcile the toolchain in L00 and lock the list before L02.
