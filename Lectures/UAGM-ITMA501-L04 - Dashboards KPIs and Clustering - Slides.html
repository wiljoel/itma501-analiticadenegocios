Part 01 · Business questions

Start with the decision, not the chart.

Executive

Are results healthy?

Use KPI cards and a trend to show status and direction.

Manager

Where should we focus?

Use ranked bars, a matrix, and filters to identify segments that need attention.

Analyst

Why is this happening?

Use distributions, relationships, and drill-through pages to investigate.

Translation chain

Question → measure → visual → action

Example: “Which markets need attention?” becomes revenue and orders by state, then a ranked bar chart and a follow-up investigation.

Part 02 · Chart selection

Useful rules. Dangerous shortcuts.

Bars

Sort them. Use them for comparison.

Lines

Use ordered time on the x-axis.

Tables

Use when exact lookup matters.

Maps

Use only when geography changes the decision.

Avoid: 3D charts, decorative rainbow colors, unsorted bars, unexplained dual axes, and truncated bar-chart axes.
Part 03 · Dashboard design

Build a visual hierarchy.

Top

Context and KPIs

Title, audience, date range, and a small number of high-signal cards.

Middle

Main answer

One comparison or trend visual should carry the page's primary story.

Bottom

Diagnosis

Matrix, detail table, or supporting chart for the next question.

Everywhere

Clarity

Aligned edges, whitespace, explicit titles, readable units, restrained color.

KPI anatomy: metric + target + threshold + owner + cadence. A number without context is a metric, not a KPI.
Part 04 · Power BI introduction

Connect. Model. Build. Interact. Explain.

  1. Get Data: choose PostgreSQL and connect to the Supabase project from L02.
  2. Model: inspect tables, relationships, data types, and grain.
  3. Build: drag fields into visual wells.
  4. Format: set titles, currency, labels, colors, and axes.
  5. Interact: add a slicer and test cross-filtering.
  6. Save: keep the `.pbix` connected to the student's project.
Aggregation check: item-level price summed across items is not the same as counting orders. Always state the grain of the number.
Lab · Olist dashboard

  2. Create cards for total orders, gross revenue, and average review score.
  3. Add a sorted bar chart for revenue by state.
  4. Add a line chart for monthly orders or revenue.

  6. Add one slicer and test cross-filtering.

Do not decorate first. Verify the numbers against SQL, then format the page.
Lab · Interpretation

Turn visuals into business answers.

Evidence

What exactly does the visual show?

Interpretation

What might the pattern mean?

Action

What could someone do next?

Limit

What does the dashboard not prove?

Example: “SP has the highest revenue in this dataset. That suggests it deserves follow-up analysis, but it does not prove that expanding there will cause future revenue to increase.”
