Foundations · U1.1

The analytical ladder.

Four rungs. Every rung requires the ones below it. Every technique you learn this term lives on one of them.

1

Descriptive

What happened?
Dashboards, reports, KPIs. "Q2 revenue was $2.1M." Covered in L03, L04.
2

Diagnostic

Why did it happen?
Root cause, drill-down. "Revenue dropped because Miami churn spiked." Woven through Description.
3

Predictive

What will happen?
Forecasts, machine learning. "These 200 customers are likely to churn." Covered in L06, L07.
4

Prescriptive

What should we do?
Optimization, recommendation, deployment. "Send this offer to those customers now." L07.
Foundations · U1.2

The four V's of Big Data.

Every dataset in this course, and every dataset you'll ever meet at work, can be sized up against these four dimensions.

V₁
Volume
V₂
Velocity
V₃
Variety
V₄
Veracity
Volume
How much? Kilobytes to petabytes. A retail POS system may push 50 GB per day.
Velocity
How fast? Batch monthly to streaming per second. IoT sensors run milliseconds apart.
Variety
What shape? Numbers, text, images, audio, JSON logs. All in one pipeline.
Veracity
How trustworthy? Data ages. Systems mislabel. Rows go missing. Assume nothing.
Foundations · U1.3

Three shapes of data.

The shape decides the tool. Get the shape wrong and you'll pick the wrong tool every time.

Shape 01

Structured

Rows and columns. Fixed schema. Reads great in SQL.
Example: orders table in a retail database. Every row has the same fields.
Shape 02

Semi-structured

Nested fields, optional keys. JSON, XML, log files.
Example: events.jsonl from a website. Every event has different properties.
Shape 03

Unstructured

Free text, images, audio, video. No schema at all.
Example: customer reviews. We'll mine 200 of these in L05.
