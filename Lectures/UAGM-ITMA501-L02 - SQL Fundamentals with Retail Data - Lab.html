SQL Fundamentals with Retail Data

Construye y consulta una base de datos relacional de un concesionario de autos en DB Fiddle para responder preguntas reales de negocio.

Herramienta: DB FiddleBase: car_dealership_schema.sqlEntrega: 18 consultas + capturas

Preparación

Asegúrate de haber ejecutado el script completo, incluyendo la creación de tablas y la inserción de datos, en tu editor SQL de DB Fiddle.

Tablas: dealers, brands, models, employees, cars, customers, sales.

Nota: PostgreSQL y MySQL no soportan TOP. Utiliza LIMIT n en los ejercicios donde se solicita “TOP”.

Conceptos cubiertos

SELECT · FROM · WHERE · ORDER BY · GROUP BY · LIMIT · DISTINCT · SUM() · AVG() · COUNT() · INNER JOIN

Preguntas

  1. (SELECT / FROM) Muestra toda la información de los concesionarios (dealers).
  2. (SELECT / FROM) Muestra el modelo, la marca (brand_id) y la categoría de todos los modelos disponibles.
  3. (DISTINCT) ¿Cuáles son los distintos colores de autos disponibles en el inventario?
  4. (DISTINCT) ¿Cuáles son los distintos puestos (role) que existen entre los empleados?
  5. (WHERE) Muestra todos los autos cuyo precio sea mayor a $28,000.
  6. (WHERE) Muestra todos los autos “Available” del concesionario con dealer_id = 1.
  7. (WHERE + AND) Muestra empleados con rol “Manager” contratados después del 2021-01-01.
  8. (ORDER BY) Muestra todos los autos ordenados por precio de mayor a menor.
  9. (ORDER BY + LIMIT) Muestra los 10 autos más caros del inventario.
  10. (COUNT) ¿Cuántos autos hay en total en el inventario?
  11. (COUNT + WHERE) ¿Cuántos autos han sido vendidos (status = 'Sold')?
  12. (SUM) ¿Cuál es el valor total de los autos disponibles?
  13. (AVG) ¿Cuál es el precio promedio de venta (sale_price)?
  14. (GROUP BY + COUNT) ¿Cuántos autos tiene cada concesionario?
  15. (GROUP BY + AVG) ¿Cuál es el precio promedio de los autos por modelo?
  16. (GROUP BY + SUM + ORDER BY) ¿Cuál es el monto total vendido por cada empleado? Ordena de mayor a menor.
  17. (INNER JOIN) Muestra cada auto vendido con el nombre y apellido del cliente que lo compró.
  18. (INNER JOIN + GROUP BY + COUNT) Muestra cada concesionario con la cantidad de empleados que tiene.

Entrega

Escribe la consulta SQL para cada pregunta y adjunta una captura de pantalla del resultado obtenido en DB Fiddle. Envía un solo documento con las 18 consultas numeradas en el mismo orden que esta guía.

Asignación basada en el esquema de concesionario de autos trabajado en clase.
