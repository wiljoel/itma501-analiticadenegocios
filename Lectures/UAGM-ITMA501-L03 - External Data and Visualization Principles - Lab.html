UAGM-ITMA501 · L03 · Laboratorio

De resultado SQL a informe en Power BI

Conectarás Power BI a la base de datos Olist que completaste en Supabase durante L02, construirás visualizaciones básicas y aplicarás principios de diseño para comunicar una conclusión de negocio con claridad.

Duración: 45 minutos Herramienta: Power BI Entrada: Base de datos Olist en Supabase Modalidad: individual o grupos de 2–3

1. Objetivos del laboratorio

  1. Conectar Power BI al proyecto Supabase completado en L02.
  2. Verificar tipos de datos y formato monetario.
  3. Construir una tabla y un gráfico de barras en Power BI.
  4. Aplicar títulos, ordenamiento, etiquetas y color con intención.
  5. Explicar qué comunica el informe y qué no permite concluir.

2. Conectar Power BI a Supabase

  1. Abre Power BI Desktop o Power BI Service, según la plataforma disponible.
  2. Selecciona Get Data → PostgreSQL database.
  3. En Supabase, abre Project Settings → Database y copia el host y el nombre de la base de datos.
  4. Introduce esos datos en Power BI y autentícate con las credenciales de la base de datos de tu proyecto.
  5. Selecciona Import y elige las tablas de Olist que utilizarás: olist_customers_dataset, olist_orders_dataset, olist_order_items_dataset, olist_products_dataset y product_category_name_translation.
  6. Selecciona Load y confirma que las tablas aparecen en el panel de datos.
Control de calidad: si Power BI no permite la conexión directa, utiliza como respaldo el resultado L02-top-customers.csv exportado en L02. No crees una base de datos nueva.

3. Construir la página del informe

Visual 1 — Tabla de detalle

  1. Inserta un visual Table.
  2. Añade customer_unique_id, customer_state y una medida de ingresos.
  3. Ordena los ingresos de mayor a menor y formatéalos como moneda.

Visual 2 — Ingreso por categoría principal

  1. Inserta un gráfico de barras.
  2. Usa la categoría del producto en el eje y una medida de ingresos en valores.
  3. Ordena las barras de mayor a menor.
  4. Añade etiquetas de datos si mejoran la lectura.

Diseño y comunicación

  1. Incluye el título Olist Top-10 Customers · L03.
  2. Elimina elementos decorativos que no aporten información.
  3. Usa un color principal y un color de énfasis; evita un arcoíris decorativo.
  4. Aplica la prueba de encogimiento: ¿se entiende la historia al alejarse de la pantalla?

4. Interpretar sin sobreafirmar

Escribe una respuesta de 100–150 palabras:

“El informe muestra ___. La consulta utilizada agrupó ___. Esto podría apoyar ___. Sin embargo, no podemos afirmar ___ porque ___.”

  • Distingue ingreso total de número de clientes.
  • No presentes la categoría principal como causa del ingreso.
  • Menciona que Olist es un dataset histórico de una plataforma específica.

5. Entrega

  1. Guarda el informe como L03-olist-top-customers-<apellido>.pbix.
  2. Entrega el archivo .pbix y la reflexión escrita.
  3. Conserva la conexión al proyecto Supabase de L02 como fuente documentada del informe.
Nota para Mac: si Power BI Desktop no está disponible, utiliza Power BI Service y sigue el flujo indicado por el instructor.
Fuente de datos: Olist Brazilian E-Commerce en Kaggle. Power BI: https://powerbi.microsoft.com/
